R&D · Privacy

Privacy-preserving similarity search

A search framework that finds the closest matches without ever seeing the data in the clear, using Paillier homomorphic encryption and a Vantage Point Tree. Optimizing the encrypted nearest-neighbour search made it 60% faster.

PythonNumPyPaillier HEVP tree
encrypted_search.pyhow it works
StepWhoWhat happens
1clientencrypts query → Enc(q)
2serverwalks the VP tree on ciphertexts
3serverhomomorphic distance per node
4serverprunes branches early −60% time
5clientdecrypts the top-k matches
